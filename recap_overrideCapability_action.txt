┌─────────────────────────────────────────────────────────────────────────────┐
│                       KEY ARCHITECTURAL INSIGHTS                             │
└─────────────────────────────────────────────────────────────────────────────┘

✅ SINGLE SOURCE OF TRUTH
   └─► createAuthoringUI() is the ONLY place where UI is defined
       - Direct mode calls it
       - Action mode calls it
       - Same UI, different data flow

✅ MODE PARAMETER ELEGANCE
   └─► mode: 'direct' | 'action' controls behavior:
       - 'direct': Saves immediately to capabilities, applies to model
       - 'action': Saves to action args via callback, deferred execution

✅ CALLBACK PATTERN
   └─► onSave callback abstracts the save mechanism:
       - Direct mode: Internal saveTexture()
       - Action mode: saveActionConfig() via callback

✅ CAPABILITY EXPOSES ACTION
   └─► OverrideCapability.addActions() registers the action
       - Widget is unaware of the action
       - Capability owns both direct usage AND action

✅ ZERO CODE DUPLICATION
   └─► Material selection UI is written once in createAuthoringUI()
       - Texture selector logic in openTextureSelectorForMaterial()
       - Restore logic in restoreOriginalTexture()
       - All reused across both modes

✅ WEBDAV PATCH SAFETY
   └─► Dictionary structure for actions:
       - Can MODE_DEL specific action by key
       - Can MODE_DEL specific material by key
       - No array merging issues

✅ CLEANUP STRATEGY
   └─► onReferencedItemDeleted() handles both:
       - Direct: Clean capabilities.override[deletedItemId]
       - Action: Clean actions referencing deletedItemId

✅ INSPECTOR REFRESH PATTERN
   └─► Direct mode: focusOnItem(itemId) → refreshes layer inspector
       Action mode: focusOnItem(nodeId) → refreshes semantic node inspector


┌─────────────────────────────────────────────────────────────────────────────┐
│                              LIFECYCLE SUMMARY                               │
└─────────────────────────────────────────────────────────────────────────────┘

DIRECT MODE:
1. Equip capability on item
2. createAuthoringUI(mode: 'direct') renders config
3. Select texture → saveTexture() → Apply to 3D model + Patch
4. Restore → restoreOriginalTexture() → Restore 3D model + Delete patch
5. Effect: Immediate visual change

ACTION MODE:
1. Add action to semantic node
2. Select target item → saveActionItemSelection()
3. createAuthoringUI(mode: 'action') renders config
4. Select texture → onSave callback → saveActionConfig() → Patch action args
5. Restore → onSave callback(null) → Delete material from action args
6. Tap node in viewer → F.ActionHandlers['override'] → Apply to 3D model
7. Effect: Deferred execution on event

BOTH MODES USE SAME UI CODE: createAuthoringUI() ✨
